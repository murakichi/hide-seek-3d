# 作業日記

作業を始める前に**直近 2〜3 件を読む**。同じ調査を繰り返さないため、
そして前回「次にやること」に書き残したところから再開するため。

作業を終えたら `YYYY-MM-DD.md` に 1 エントリ追記する（同じ日なら同じファイルに足す）。

## 書き方

```markdown
## HH:MM タイトル

**やったこと** — 何を変えたか。1〜3 行。

**分かったこと** — 観測した事実。推測と区別して書く。
数値やトレースの出力など、次に読む人が再現できる形で残す。
「たぶん〜だと思う」で終わらせない。確かめていないなら確かめていないと書く。

**次にやること** — 続きがあるなら具体的に。無ければ「なし」。
issue を立てたなら番号を書く。
```

## 何を残すか

価値があるのは**うまくいかなかったこと**と**意外だったこと**。

- 試して駄目だった案とその理由（同じ案を再発明しないため）
- 予想と違った観測（例: 速度を上げたら逃げ側が弱くなった）
- 数値の変化（勝率は `docs/balance-log.md` に、経緯はここに）

うまくいった変更の内容そのものは git log に残るので、ここでは繰り返さない。
