# Issue

このプロジェクトはリモートを持たないので、issue はここにファイルとして置く。
1 ファイル 1 件、`NNN-slug.md`。番号は既存の最大値 + 1。

## いつ立てるか

- 今の作業では直さないが、直すべきだと分かった問題
- 原因が分かっていないので、調査自体が 1 サイクルぶんの作業になる問題
- 作業中に気づいた別件（**その場で直そうとしない**。1 サイクルで直すのは 1 つ）

逆に、その場で直せる小さなものは issue にせず直す。

## 形式

```markdown
---
status: open        # open | closed
priority: high      # high | medium | low
---

# NNN タイトル

## 症状
観測できる事実。数値やトレース出力を添える。

## 分かっていること
調べた範囲。試して駄目だった案があればその理由も。

## 分かっていないこと
次に確かめるべきこと。

## 解決 (closed のときだけ)
何が原因で、どう直したか。日付とコミットを添える。
```

## 進め方

`/improve-ai` が open の issue を優先度順に拾って着手する。
着手したら status は open のまま、分かったことを追記していく。
直ったら `status: closed` にして「解決」節を書く。閉じた issue は消さない
（同じ問題が再発したときに、前回何をしたかが分かる）。
