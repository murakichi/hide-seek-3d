# 001 1v1 の逃げ側勝率が低い

## 症状

24 試合で 12.5%。2v2 が 25.0%、3v3 が 29.2% なので、1v1 だけ明らかに低い。
初補足までの時間は 50.1 秒（準備 32 秒 + 追跡 18 秒）。

## 分かっていること

- **硬直は原因ではない。** `npm run tune` 前の `src/sim/_probe.ts` による計測で、
  1v1 の追跡フェーズ中に移動入力がゼロになるティックは 0%（3v3 は 4.7% あった）。
  逃げてはいるが追いつかれている。
- 人数別に見た「個人あたりの生存率」は 1v1 12.5% / 2v2 12.5% / 3v3 11% でほぼ一定。
  つまり多人数戦の勝率が高いのは「誰か 1 人が残れば勝ち」というルールの効果であり、
  1 対 1 の逃げ切り能力そのものは人数によらず低い。
- 速度差は逃げ側 9.4 / 鬼 8.8。鬼のダッシュ消費は 1.5 倍にしてあるが、
  この変更で勝率は動かなかった（12.5% のまま）。
- 拠点が隅に選ばれる問題は修正済み（壁際にペナルティ）。それでも 1v1 は改善しなかった。

### 2026-08-10 追記（`/improve-seeker` の調査より）

**「捕まる直前に何が起きているのか」と「遮蔽で視線を切れているか」に答えが出た。**

視線は切れている。1v1 の 48 試合で見失いイベントは **308 回**。
`npm run trace -- --hiders 1 --seekers 1 --find-loss` で見た試合（seed=1234）でも、
追跡開始から捕獲までの 16.7 秒で発見と見失いを 3 往復している。

```
発見 t=33.8  鬼#1 が 逃#0 を (16.7,-9.0) で捕捉 (距離 14.1)
見失い t=34.1
発見 t=35.3  (距離 12.7)   見失い t=36.4
発見 t=42.6  (距離 11.7)   見失い t=43.9
捕獲 t=48.7
```

離脱もできている。見失われた時点からの距離は 2 秒後 15.1 m、4 秒後 22.9 m、6 秒後 24.8 m
（`npx tsx src/sim/_probe.ts shake 1 1 48`）。

にもかかわらず **捕獲 40 件のうち 35 件（88%）が、視線を切ってから 6 秒以内に起きている。**
つまり 1v1 の負けは「逃げ方が悪い」のではなく、**25 m 離れて遮蔽に入っても再発見される**
＝逃げ切れる場所が盤面に無いことによる。行動側で解ける問題ではないと判断し、
issue #002 を立てた。この issue の主因もそちらにあると考えている。

## 分かっていないこと

- 煙幕（2 回）が実戦で使われているか、使って効果が出ているか。**依然として未計測。**
  ただし煙幕なしでも視線は十分切れている（見失い 308 回）ので、
  煙幕は現状ほとんど勝敗に寄与していない可能性が高い。
- 上記が本当に主因なら、issue #002 のルール変更後に 1v1 も一緒に改善するはず。
  改善しなければ 1v1 固有の要因が別にあることになる。
