# 001 1v1 の逃げ側勝率が低い

## 症状

24 試合で 12.5%。2v2 が 25.0%、3v3 が 29.2% なので、1v1 だけ明らかに低い。
初補足までの時間は 50.1 秒（準備 32 秒 + 追跡 18 秒）。

## 分かっていること

- **硬直は原因ではない。** `npm run tune` 前の `src/sim/_probe.ts` による計測で、
  1v1 の追跡フェーズ中に移動入力がゼロになるティックは 0%（3v3 は 4.7% あった）。
  逃げてはいるが追いつかれている。
- 人数別に見た「個人あたりの生存率」は 1v1 12.5% / 2v2 12.5% / 3v3 11% でほぼ一定。
  つまり多人数戦の勝率が高いのは「誰か 1 人が残れば勝ち」というルールの効果であり、
  1 対 1 の逃げ切り能力そのものは人数によらず低い。
- 速度差は逃げ側 9.4 / 鬼 8.8。鬼のダッシュ消費は 1.5 倍にしてあるが、
  この変更で勝率は動かなかった（12.5% のまま）。
- 拠点が隅に選ばれる問題は修正済み（壁際にペナルティ）。それでも 1v1 は改善しなかった。

## 2026-08-10 追記（`/improve-balance`）— 行動側へ差し戻し

**1v1 固有の問題ではなかった。** 追跡フェーズを計測したところ、
どの構成でも同じことが起きていた（`src/sim/_probe.ts`）。

- 追跡開始から 2.7〜5.9 秒で全員見つかる。発見から捕獲まで 12.4〜15.7 秒しかもたない。
- 視線は 1 人あたり 5〜6 回切れているが、切ってから 1.6〜2.2 秒で再発見される。
- **原因は逃げる側がダッシュを使っていないこと。** 追われている間の使用率は 17〜26%、
  平均スタミナは 88〜92 残っている。鬼は 64〜72% 使ってスタミナ 33〜46 まで削っている。
  距離が最も開いた瞬間でも平均 0.1〜0.4 m しか稼げていない。

ルールとしては逃げ側が有利（速度 9.4 対 8.8、ダッシュ消費 34 対 52、
使い切れば平均速度で 16% 速い）ので、**バランス側では解かない**。
上に書かれた「拠点の隅ペナルティ」「鬼のダッシュ消費 1.5 倍」がどちらも効かなかったのも、
速度資源が余っている状態では速度側の定数が効かないため。

遮蔽側も潰した。小さい箱を目線より高くして遮蔽を実質 2.5 倍にしたが、
見られている割合が 3v3 で 67.8% → 45.9% に下がっても勝率は動かなかった
（`docs/balance-log.md` 2026-08-10 の節）。

原因の追跡は issue #002 に移す。この issue は「勝率が目標に届かない」という
症状の記録として open のまま残す。#002 が閉じたら再測定して判断する。

## 分かっていないこと

- 捕まる直前に何が起きているのか。速度負けなのか、進路を読まれて回り込まれているのか、
  袋小路に入っているのか。`npm run trace -- --hiders 1 --seekers 1 --find-loss --interval 3`
  で捕獲前 10 秒の座標と両者の距離推移を見る必要がある。
- 煙幕（2 回）が実戦で使われているか、使って効果が出ているか。未計測。
- 遮蔽で視線を切れているか。トレースの「見失い」イベントが 1v1 で何回起きているか未集計。
